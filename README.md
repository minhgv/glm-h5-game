## 🏗 Architecture & Design Standards
- **Resolution & Rendering:** Native 1080x1920 Full HD Canvas / Procedural Vector Graphics / CSS GPU-accelerated layers.
- **Audio:** Procedural WebAudio Oscillator SFX (0 external audio bytes, zero-latency mobile touch unlock).
- **Control:** Touch-first ergonomics, mobile-responsive portrait & desktop container scaling.
- **Packaging:** Standalone per-game directory with complete `PRD.md`, `PROMPT.md`, and clean buildable source.
