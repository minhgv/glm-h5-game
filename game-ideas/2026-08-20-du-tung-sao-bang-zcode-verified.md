# Comet Slingshot

- **Date:** 2026-08-20 · **Revised:** 2026-08-29 — aligned to repo standards: template/engine architecture (no single-file), English UI copy behind an STR i18n table, saves via `engine/storage.js`.
- **Slug:** `comet-slingshot` — target folder `games/comet-slingshot/`
- **Genre:** Arcade/casual orbital-slingshot infinite climber — one thumb, real pendulum physics (latch anchor → swing → tangential fling), near-miss graze, combo score-chase, endless world generated by altitude.
- **Pitch:** One finger, one decision: HOLD to swing around an anchor, RELEASE to slingshot up the Milky Way Tower on pure inertia — shave past hot-pink lasers for grazes, keep the combo chain exploding, and when you die, watch yourself fly in a 2.5-second replay before instantly playing again.
- **Origin:** GLM-5.3 (Z.AI Coding Plan); original Vietnamese brief "Đu Tung Sao Băng".

=== TECHNICAL BLUEPRINT ===
- Palette: bg vertical gradient #05060F → #0B1030 → #141B45 + 3 parallax
  starfield layers; comet #00F0FF with a cyan→transparent gradient tail;
  anchor #FFC94D (amber); hazard #FF2E88 (neon pink); graze/flying score
  #3DFFB4 (mint); UI #EAF2FF; death fog at the pit #3A0CA3 → #7209B7. Glow via

- Physics (1080p logical px): g = 2000 px/s²; on a tether of radius r:
  θ'' = −(g/r)·cosθ − 0.02·ω; ω at latch = velocity projected on the tangent
  (v·t̂)/r — energy-preserving, no teleport; semi-implicit integration:
  ω += θ''·dt then θ += ω·dt; pos = anchor + r·[cosθ, sinθ]; max tether
  480 px; release: v = ω·r·t̂ (tangent direction follows the sign of ω).
- Perfect Release: post-release velocity within ≤ 12° of straight up → speed
  boost x1.18, hitstop 40 ms, gold radial flash.
- Anchor pick on press (within 480 px): score = dot(normalize(anchor−player),
  normalize(v)) + (player.y − anchor.y)/1500 — prefers higher anchors in the
  flight direction; no valid anchor → keep free-falling (keeps the decision
  tense).
- Combo 'River of Stars': +1 chain on a Perfect Release, a Graze, or latching
  an anchor ≥ 200 px above the previous one; multiplier = min(8, 1 +
  floor(chain/4)); 3 s without an event resets the chain; an arc around the
  comet displays the decay countdown.
- Scoring: height/10 (ticked at milestones) + graze·50·mult + perfect·100·mult;
  first run of the day x2 (daily return hook).
- Difficulty: diff = min(1, h/12000); laser-gate spawn probability p = 0.15 +
  0.5·diff; gate rotation speed = 0.8 + 2.2·diff rad/s; shaft narrows:
  horizontal bounds = W·(0.42 − 0.10·diff); death-fog climb speed = 60 +
  240·diff px/s.
